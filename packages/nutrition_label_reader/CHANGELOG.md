# Changelog

## 0.1.0

- Pure Dart parser for nutrition labels: numbers, units, rows, columns,
  serving size, energy, salt and sodium, plausibility flags and serving
  scaling.
- English vocabulary (unverified) and a vocabulary interface.
- Pigeon schema for text recognition, with Dart output only.
- `NutritionLabelReader` facade, platform interface and a fake for tests.
- Dart-only example with a synthetic label.
- No native code yet.
